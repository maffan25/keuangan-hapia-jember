# Kas HAPIA

Web manajemen arus keuangan dan kas Himpunan Alumni Pesantren Islam Al Irsyad (HAPIA).
Situs statis (HTML, CSS, JS) tanpa proses build. Tampilan dashboard gelap bergaya kaca (tema Ethereal bawaan); nama, logo, dan latar belakang dapat diubah lewat ikon pengaturan. Animasi klik, latar aurora bergerak, dan cetak laporan A4 profesional. Fitur: ringkasan keseluruhan, pengelompokan per event (pemasukan, pengeluaran, grafik, ringkasan), laporan bulanan, ekspor CSV dan cadangan.

## Deploy
1. Unggah semua isi folder ini ke repositori GitHub.
2. Di Vercel: Add New > Project > pilih repositori. Framework Preset: Other. Build Command dan Output Directory dikosongkan.
3. Deploy.

## Catatan data
Data tersimpan di localStorage peramban perangkat yang dipakai. Gunakan menu Laporan > Unduh cadangan secara berkala.
